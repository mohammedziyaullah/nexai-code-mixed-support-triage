\# Code-Mixed Support Triage Assistant



\*\*NexAI Hack 2026 — Problem Statement 1.1\*\*



\## Problem Overview



Indian customers often write customer-support messages using a mixture of English and regional languages, such as Tanglish and Hinglish. This project aims to classify these messages, identify urgency, draft a suitable reply, and escalate uncertain cases to a human support agent.



\## Mandatory Requirements



1\. Classify customer messages by intent and urgency and return a confidence score.

2\. Include at least 30 team-written Tanglish and/or Hinglish test messages with expected labels, and display classifier results in the application.

3\. Provide an inbox where users can submit messages and see the predicted intent, urgency, draft reply, and human-escalation status with a reason when confidence is below the configured threshold.
